
# ShopNest - Smart Shopping Portal

## Project Description

ShopNest is an online shopping portal developed using
HTML, CSS, JavaScript and JSON.

It provides a simple shopping experience with dynamic
product loading, category filtering and shopping cart
functionality.

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript
4. JSON
5. Fetch API
6. Async-Await
7. LocalStorage

## Main Features

1. Home page and navigation.
2. Dynamic product listing.
3. JSON-based product catalog.
4. Category filtering.
5. Add products to cart.
6. Remove products from cart.
7. Increase and decrease quantities.
8. Store cart using LocalStorage.
9. Checkout form validation.
10. Product enquiry form.
11. SPA-style navigation.
12. Responsive user interface.

## Project Practicals

PR4: Asynchronous Data Handling using JSON and APIs.

PR5: SPA Concepts and Final Project Integration.

## How to Run

1. Open the project in Visual Studio Code.
2. Install Live Server if required.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. Explore the ShopNest shopping portal.

## Conclusion

ShopNest demonstrates dynamic data handling,
shopping cart management, client-side validation
and SPA-style navigation using JavaScript.
